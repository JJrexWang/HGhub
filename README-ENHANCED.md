# HGhub 增强版（下载 + 管理）

基于上游 [Minireel/HGhub](https://github.com/Minireel/HGhub) **v1.1.0（8665ffc）** 的个人自用增强分支 `enhanced`，版本 `1.2.0-enhanced.1`。
许可证与上游一致：**PolyForm Noncommercial 1.0.0**，仅限非商业、个人学习与自用；分发时须保留上游 LICENSE 与 Required Notice。

## 定位与边界

- 个人**离线自用**：给自己能正常播放的内容留离线副本，不搬运、不二次分发、不出售。
- **不轰炸上游**：全局同时只跑 1 个下载任务，任务内分片顺序下载（并发 1）；「整部下载」只是逐集排进这个顺序队列。失败重试带上游既有重试逻辑，播放地址过期时只自动刷新一次。
- 封面/播放列表的内存缓存策略与上游保持一致，未改小、未关闭。

## 新增功能

### 下载（Rust：`src-tauri/src/download.rs`）
- 入口：播放页右侧「下载」按钮（带状态/进度）、选集面板（每集状态点 + 下载本集 + 整部下载）。
- 流水线：开始下载时才取新鲜播放地址（`auth_key` 会过期，旧地址不落盘）→ 解析 m3u8（主列表自动选最高码率、AES-128 密钥与 IV、EXT-X-MAP）→ 逐片下载并 AES-128-CBC 解密 → 拼接成品：TS 流拼为 `.ts`，fMP4 拼为 `.mp4`，均可直接被主流播放器播放，无需 ffmpeg。
- 断点续传：分片先落在 `<成品名>.part/` 目录，已完成分片跳过；暂停/软件重启后可续（启动时未完成任务自动置为「已暂停」）。
- 队列管理：暂停 / 继续 / 取消 / 失败重试 / 删除（连同分片与索引一起删）。

### 命名规则（按作品 + 集数）
```
<下载根目录>/
├─ downloads.json                 索引
└─ <作品名>/                      按作品建文件夹
   ├─ cover.jpg                   解密后的封面快照
   ├─ <作品名> - 第01集.ts
   ├─ <作品名> - 第02集 初遇.ts   （有独立集标题时叠加，集号重复的不叠）
   └─ <作品名> - 第03集.ts.part/  未完成任务的分片目录，完成后自动清除
```
- 集号至少 2 位补零（总集数 ≥100 时 3 位）；作品名做文件名清洗（非法字符、控制字符、超长截断）。

### 管理（前端）
- **下载管理页**（「我的 → 下载」或设置页进入）：进行中队列（进度条/暂停/继续/取消/重试/删除）；已完成按作品聚合（集数、总大小、最近下载时间）；按作品名/文件名搜索；最近/大小/名称排序；批量多选删除、删单集、删整部；存储统计；桌面端「打开目录」。
- **我的 → 下载 tab**：按作品聚合的封面卡片，点开直接离线播放。
- **设置 → 下载**：占用统计、进入管理页、打开下载目录、命名规则说明。
- 元数据（标题/封面/集数/时长）在入队时快照到本地索引，作品下架或离线时下载列表仍可正常显示。

### 离线播放
- 已下载的集在播放页自动优先走本地（标题旁有「离线」角标），观看进度与在线共用一套记录，可续播。
- TS 成品经本地生成的单分片 HLS 列表由 hls.js 转封装播放；mp4 成品由 video 元素直读。本地供流支持 Range（拖动进度）。

## 平台说明
- 桌面（Windows/macOS）：下载目录在应用数据目录 `downloads/` 下，可在下载管理页一键打开；文件是标准 `.ts`/`.mp4`，可用任意播放器播放、自行拷贝。
- Android：应用私有目录存储，仅 App 内离线播放与管理（系统分区存储限制，导不出到公共下载目录）。

## 构建
与上游相同：`pnpm install && pnpm app:build`（Windows 出 NSIS）。Android：`pnpm android:init && pnpm android:build`。

## 已知限制
- 上游若改接口字段或 HLS 加密方式（换 key 规则、DRM），下载会失败但有明确报错；普通 AES-128 HLS（含主列表、key 轮换、显式/序列号 IV）均已处理。
- 下载目录暂不支持自选（固定在应用数据目录），后续版本可加。
